# TASK — MVP Enquete Coletiva (Angular + Supabase)

## Objetivo

Criar uma aplicação web extremamente simples e mobile-first para organizar pequenas enquetes compartilháveis.

Exemplo:
- Festa junina
- Churrasco
- Café coletivo
- Quem vai levar o quê

Usuário acessa o link:
- escolhe um item;
- informa o nome;
- confirma.

Sistema:
- contabiliza quantidade;
- lista os nomes por item.

# Funcionalidades MVP

# 1. Criar enquete

Tela simples contendo:

## Campos
- título da enquete
- lista dinâmica de itens

## Exemplo

Festa Junina da Família

[ Milho ]
[ Refrigerante ]
[ Paçoca ]

## Ações
- adicionar item
- remover item
- criar enquete

---

# 2. Gerar link compartilhável

Após criar:
- gerar ID automático;
- navegar para rota pública.

Exemplo:

/poll/abc123

---

# 3. Participar da enquete

Tela pública extremamente simples.

## Fluxo

### Cabeçalho
O que você vai levar?

### Lista de opções
( ) Paçoca
( ) Refrigerante
( ) Milho

### Campo
Seu nome

### Botão
Confirmar

---

# 4. Resultado em tempo real

Abaixo da votação mostrar:

Paçoca (2)
- João
- Maria

---

# 5. Evitar duplicidade simples

Usar:
- localStorage

Salvar:
poll_voted_<pollId>

Se já votou:
- bloquear novo envio;
- apenas exibir resultado.

Não precisa segurança avançada.

# Estrutura do banco — Supabase

## Tabela: polls

id uuid primary key
title text
created_at timestamp

---

## Tabela: poll_items

id uuid primary key
poll_id uuid
name text
created_at timestamp

---

## Tabela: poll_answers

id uuid primary key
poll_id uuid
poll_item_id uuid
person_name text
created_at timestamp
